# LTE — Long-Term Evolution (4G)

**What it is.** The 4G cellular standard, specified by 3GPP. Cellular is *the*
solution for wide-area mobile Internet: hundreds of Mbps, more mobile-broadband
devices than fixed ones.

**Same or different from the wired Internet?**

| Same | Different |
|---|---|
| edge/core split, network of networks | a different wireless link layer |
| uses HTTP, DNS, TCP, UDP, IP, NAT, SDN | **mobility as a first-class service** |
| data/control plane separation | user identity via SIM |
| tunnelling | subscription business model, home network versus roaming |

That last difference is the whole point: cellular *architects* for mobility, while
Wi-Fi only gets it by accident (same subnet) or not at all.
