Indicator random variables. If 𝑋 only takes 0 or 1, 𝐸[𝑋] = Pr[𝑋 = 1].
Linearity of expectation. Given two random variables 𝑋 and 𝑌 (not
necessarily independent),
                        𝐸[𝑋 + 𝑌] = 𝐸[𝑋] + 𝐸[𝑌].

Example. Shuffle a deck of 𝑛 cards; turn them over one at a time; try
to guess each card. Suppose you can't remember what's been turned

Q. What’s the expected number of correct guesses?

A. (surprisingly effortless using linearity of expectation)
  Let 𝑋𝑖 = 1 if 𝑖 th guess is correct and 0 otherwise.
  Let 𝑋 = number of correct guesses = 𝑋1 + ⋯ + 𝑋𝑛 .
  𝐸[𝑋𝑖 ] = Pr[𝑋𝑖 = 1] = 1/𝑛.
  𝐸[𝑋] = 𝐸[𝑋1 ] + ⋯ + 𝐸[𝑋𝑛 ] = 1/𝑛 + ⋯ + 1/𝑛 = 1.

Q. What’s the worst-case running time of the try-and-check algorithm?

A. Unbounded. But the probability of running for a long time is

For many problems, randomized algorithms are often simpler and
practically more efficient than deterministic algorithms
   •  It remains an open problem whether randomized algorithms can
