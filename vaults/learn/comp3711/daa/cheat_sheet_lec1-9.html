COMP3711 DAA — Midterm Cheat Sheet (Lec 1–9 · key formulas, algorithms & facts)

1. Recursion & Divide-and-Conquer

Recursion: ① base f(1) ② assume f(n−1) ③ build f(n).

Tower of Hanoi: T(n)=2T(n−1)+1, T(1)=1 → T(n)=2ⁿ−1.

D&C template: split → solve subproblems → combine.

Mergesort: sort halves, merge. T(n)=2T(n/2)+n = Θ(n log n).

Max subarray: Kadane V=max(V+A[i],A[i]); Vmax=max(Vmax,V) → Θ(n). D&C crossing = max suffix(left) + max prefix(right); T=2T(n/2)+n.

2. Multiplication

Split: a=2^(n/2)a₁+a₀, b=2^(n/2)b₁+b₀.

  • Naive D&C (4 mults): T=4T(n/2)+n = Θ(n²).
  • Karatsuba (3 mults): a₁b₀+a₀b₁ = (a₁+a₀)(b₁+b₀)−a₁b₁−a₀b₀. T=3T(n/2)+n = Θ(n^log₂3)≈Θ(n^1.585).
  • Matrix: Θ(n³).

3. Master Theorem

T(n)=aT(n/b)+f(n); compare f(n) vs n^(log_b a):

ConditionSolution
f=O(n^(log_b a − ε))Θ(n^(log_b a))
f=Θ(n^(log_b a))Θ(n^(log_b a) log n)
f=Ω(n^(log_b a + ε)), regularΘ(f(n))

Quick (f(n)=n): a>b → Θ(n^(log_b a)); a=b → Θ(n log n); a<b → Θ(n).

Expansion/tree: unroll to n/b^k=1 (k=log_b n); sum level costs.

4. Randomized / Probabilistic

  • E[X]=Σ i·Pr[X=i]; indicator ⇒ E[X]=Pr[X=1]; linearity (no independence).
  • Hash chaining: expected collisions ≤ n/m.
  • Birthday: E[#pairs]=C(k,2)/n; ≈1 at k≈√(2n).
  • Fisher–Yates: for i=1..n swap A[i]↔A[Random(1,i)] → O(n), uniform. ❌ Random(1,n) not uniform.
  • Hiring: E[hires]=Hₙ=1+½+…+1/n=Θ(log n).
  • Geometric: P(m)=p(1−p)^(m−1); E[X]=1/p.
  • Coupon collector: E=n·Hₙ=Θ(n log n).
  • Series: finite Σa·r^(i−1)=a(1−r^j)/(1−r); infinite=a/(1−r); Hₙ=Θ(log n); log(n!)=Θ(n log n).

5. Quicksort & Selection

Partition (pivot A[r]):

x←A[r]; i←l−1
for j←l to r−1:
  if A[j] ≤ x: i++; swap A[i],A[j]
swap A[i+1],A[r]; return i+1

Random pivot → expected Θ(n log n), worst Θ(n²).

Compare fact: zᵢ,zⱼ compared iff one is first pivot among {zᵢ..zⱼ}: Pr=2/(j−i+1).

Randomized Select (i-th smallest), expected Θ(n):

Select(A,l,r,i):
  if l=r return A[l]
  random pivot; swap with A[r]; m←Partition
  k←m−l+1
  if i=k return A[m]
  if i<k return Select(A,l,m−1,i)
  else   return Select(A,m+1,r,i−k)

Good pivot (25–75%) prob ½ → size ×¾ → Θ(n).

Two sorted arrays, k-th: compare A1[s1+k/2−1] vs A2[s2+k/2−1], discard smaller half, k←k−k/2; base k=1 → min. Θ(log k).

6. Heaps / Priority Queues

Max-heap = complete binary tree, parent ≥ children. 1-indexed: root A[1]; left=2i; right=2i+1; parent=⌊i/2⌋; height ⌊log n⌋.

OpTime
Max-Heapify (bubble down)O(log n)
Build-Max-Heap (i=⌊n/2⌋..1)O(n)
Extract-Max / InsertO(log n)
HeapsortO(n log n), in-place, not stable
Max-Heapify(A,i): k=largest(i,2i,2i+1)
  if k≠i: swap A[i],A[k]; recurse(k)
Extract-Max: A[1]←A[n]; n−−; Heapify(1)
Heapsort: Build; for i=n..2: swap A[1],A[i]; n−−; Heapify(1)

7. Linear Sorts & Lower Bounds

Decision tree: N leaves ⇒ height ≥ log₂N. Search: n+1 outputs → Ω(log n). Sort: n! outputs → Ω(n log n).

Counting sort Θ(n+k):

C[A[j]]++ ; C[i]+=C[i−1]   // C[i]=#≤i
for j=n..1: B[C[A[j]]]←A[j]; C[A[j]]−−  // stable

Radix sort Θ(d(n+k)): LSD→MSD, stable counting sort per digit: digit=(A[j]/exp) mod 10.

Quick picks

  • Sort: Mergesort (guaranteed) / Quicksort (expected) / Heapsort (in-place); integers → Counting/Radix.
  • k-th smallest → Randomized Select Θ(n); two sorted arrays → Θ(log k).
  • Max+insert → Heap. Halves+combine → D&C. Expectation → indicators+linearity. Adversarial input → randomize.
